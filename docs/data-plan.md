# 买点观察：持久化与日线方案

## 交付范围
1. 修复两条路径独立判断与日期一致性；双路径不自动增加仓位。
2. D1 保存真实 OHLCV（日线），按标的、交易日、来源去重；保留来源及抓取时间。
3. 获取失败时读取数据库，明确显示旧数据、过期与写入失败，不伪装最新行情。
4. 日线图展示收盘、50/200日均线和成交量。均线先计算完整历史再截取显示区间；200日不足就留空。
5. 信号快照保存实际观察时间、规则版本、输入值及各来源日期。不得把当前计算伪称历史当日信号。

## 边界
日线源仍为已有公开来源。数据库只解决保存问题。刷新时按需更新，无人访问时不宣称定时采集。持仓与交易执行记录尚未接入，仓位仅为规则上限示例，不是可执行加仓指令。Sites 托管收费未核实，不承诺套用个人 Cloudflare 免费额度。

## 验收
- 完整低吸路径不被趋势缺失项拦截；日期错位不能触发对应路径。
- 首次抓取入库、重复更新不产生重复日线；来源失败可读已有数据。
- 数据库错误不显示保存成功；缺失/过期不生成可执行买点。
- 线上确认表存在且包含真实标的数据，再报告完成。
- 桌面与窄屏图表可读；价格、日期及样本数量与接口一致。
