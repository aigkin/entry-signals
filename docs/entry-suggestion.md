# 日线买点观察台 · 建议层 v1

卡片保留 SMA50 至 1.10 × SMA50 的规则区间；系统建议只在一条完整路径满足时产生。到价/接近/观察是价格位置，不是买入建议。

建议层共享 detail-checks 的路径核对，趋势额外要求20日相对 SOXX ≥ 0%；这是试用门槛，尚未回测或样本外验证。低吸与趋势独立，缺行业广度只拦截趋势；低吸仍需 VIX 同日、回撤企稳、量比、有效估值/预期与经营依据。ETF使用独立规则，当前不给公司建议。

建议价区使用当前已完成日线的输入，其他证据固定：
- 趋势：(SMA50, min(1.10 × SMA50, 基准价值 / 1.05)]。
- 回撤企稳：(前日高点, min(0.85 × 60日最高收盘, 基准价值 / 1.15)]。

基准价值由当前收盘和已保存的 upside 还原。价区下限不含；触价本身不构成建议，下一日必须重新检查量能、估值空间、日期与风险。缓存、数据异常、经营风险未解除时不给建议区间。

首页共享一次 VIX 获取，不为七只标的重复请求；保留浏览器和服务器缓存首屏。来源失败与缺失显示来源、数据日期及核查时间。完整规则尚未验证，不输出仓位或下单。

相对强弱方法参考：[Fidelity Relative Strength Comparison](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/relative-strength-comparison)。20日和0%门槛为本项目试用设置，不来自该文档的收益保证。

已接入：SOXX同日行业广度、本地只观察、日线通知去重。后续：七只标的的技术回测和样本外验证。缺历史估值/共识时不可声称回测了完整建议层。

## 阅读与复核

建议区间明确标注趋势路径或回撤路径。趋势与规则区间共享 SMA50 下沿，但估值可能收紧上沿；回撤使用前日高点与60日最高收盘，与 SMA50 区间独立。首页显示同日广度与覆盖家数；不使用自选股广度代替行业成分股覆盖。每张卡每次渲染只计算一次 suggestion，价区和状态复用该结果。暂无建议的卡片打开详情时默认进入买点复核：缺失及未达到项直接展开，已满足项折叠；切换路径后维持这一展示顺序。
